# HR — PD/OM messages, buffer and authorization

> PD message handler (`if_hrbas_message_handler`) and its collector classes, the OM buffer and its memento, the PD authorization/context helper classes.
> Related: `hr-pd.md` (the read path and object layer these serve), `hr-pd-write.md` (the trial this buffer pairs with), `errors.md` (message handling and the trial/LUW rules), `logging.md` (where the accumulated messages end up), `security.md` (HR authorization).

## Messages, buffer and authorization

- **[P1]** PD message handler — `if_hrbas_message_handler` (ref type `hrbas_msg_handler_if_ref`), **not** `if_hrpa_message_handler` of the PA layer. Producer side — `add_message( EXPORTING message TYPE symsg field_list OPTIONAL detail_level TYPE ballevel DEFAULT '1' context TYPE REF TO if_hrbas_message_context OPTIONAL )`. Collector side — two public classes with the same method set (`add_messages( message_handler add_detail_level default '0' )`, `has_message`/`has_error`/`has_abend`/`has_warning`/`has_info`/`has_success`, `get_message_list`/`get_error_list`/`get_abend_list`/`get_warning_list`/`get_info_list`/`get_success_list`, event `message`), all `RAISING cx_hrbas_violated_assertion` — keep them in a `TRY`: `cl_hrbas_message_list` (exporting `hrbas_message_tab`) and `cl_hrbas_message_handler` (exporting `hrbas_msg_tab`) — pick by the tab type your caller handles. Discarding is intentional only — `cl_hrbas_dummy_message_handler` (the PA `cl_hrpa_dummy_message_handler` analog); for re-mapping a foreign handler into yours — `cl_hrbas_message_remap=>remap( )` / `cl_hrbas_message_struct_remap~set_remapping( )`. `update_mode` here is `hrbas_update_mode` (PA uses `hrpad_update_mode`). <!-- rule: pd-message-layer -->

- **[P2]** PD buffer — `cl_hrbas_rhombuffer=>get_instance( )` (`create private`): `check_record_exist( )`, `buffer_access( )`/`buffer_access_plain( )` for a direct by-key read, and `export_memento( )`/`import_memento( )` — a snapshot of the OM buffer that can be restored afterwards. Restore the memento when only the *writes* must be rolled back; `initialize( )` instead drops the read buffer too (`hrpa-bl-trial-close`) and costs the refill. `cl_hrbas_readonly_buffer` is the read-only half — hand a reader this buffer where it must not write.

- **[P3]** PD object/context helpers — instead of hand-written checks: `cl_hrbas_infotype_services` (statics) `is_external_otype( )` / `is_external_infty( )` / `is_external_relation( )` / `is_ext_otype_no_inrel( )` (the object is external — `a_is_external_object`, `hr-pd.md`), `is_standard_otype( )`, `is_infty_allowed_for_otype( )`, `get_timeconstraint( )`, `determine_infty_from_dbtab( )`, `get_type_nnnn( )`, `check_istat_operations( )`, `convert_tab_container_to_pnnnn( )`/`convert_tab_pnnnn_to_container( )`. Do not confuse it with `cl_hr_infotype_services` (a different class — it holds `assert_matching_error_states( )`, the PD postcondition the framework's own write methods call). Own infotype logic in PD implements `if_hrbas_infty_bl` (`insert`/`modify`/`delete( update_mode execute_mode default infotype_operation no_auth_check message_handler → is_ok CHANGING container )`, `post_read`, `read`) and is built via `cl_hrbas_infotype_factory=>get_infotype_logic( )` / `get_infotype_specific_bl( )` / `get_infotype_generic_bl( )` — do not call an infotype logic class directly.

- **[P3]** The classic buffer helpers are that same layer driven by hand — `RH_GET_BUFFER_PLOG_TAB`/`RH_SET_BUFFER_PLOG_TAB` (and the halves `RH_GET_BUFFER`/`RH_SET_BUFFER`, `RH_GET_PLOG_TAB`/`RH_SET_PLOG_TAB`), `RH_CLEAR_BUFFER`, `RH_CLEAR_PLOG_TAB` (SP00, group `RHAP`) and `HR_INITIALIZE_BUFFER` (PBAS, group `HRAC`): the tab-carrying pair hands the whole OM buffer out as `HRBUFFER`/`P1000`/`HRDBTAB` tables and writes it back — a hand-rolled memento, i.e. exactly what `export_memento( )`/`import_memento( )` above does; `RH_CLEAR_BUFFER` empties the buffer outright (the `initialize( )` half). Where the class has a method, call the class — hand-carrying the buffer tables is the same duplication as a hand-written PD read (`hr-pd.md`).

- **[P3]** PD authorization — `cl_hrbas_authorization` (`create public`): `auth_check_without_context( )`/`auth_check_with_context( )`, `auth_check_timeperiod( )`, `auth_check_relationship( )` — for the `no_auth_check` decision (`hr-pd.md`) and for a standalone check; details — `security.md`.
